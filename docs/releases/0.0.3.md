Yurlungr 0.0.3 is a hardening release: encrypted phone-to-phone sharing, safer saving, and fewer ways for agents, git or the network to crash the app or lose work.

### Two phones: new pairing protocol (update both phones)

- The pairing code is never sent any more. Both phones prove they know it with a challenge-response, so a device without the code can't pair or pose as the host.
- After pairing, every message is encrypted and authenticated with keys derived from the code. Relaying, changing, replaying or reordering messages closes the connection.
- With *Also allow local Wi-Fi*, the host still refuses connections from outside Tailscale and private network ranges.
- Unpaired connections must pair within 10 seconds, and oversized messages are refused.
- Turning Wi-Fi sharing on or off no longer fails with "address in use". *Exit* in the notification now also stops sharing.
- **Breaking:** phones on 0.0.2 or older can't pair with 0.0.3. A new client connecting to an old host gives up after 10 seconds and asks you to update both phones.

### Editor

- Saving writes a temporary file and renames it over the original, so a full disk or a crash can't leave a file empty or half-written. Permissions and symlinks are kept.
- If a file changed on disk after you opened it (an agent, `git pull`, a stash pop), Save offers Overwrite, Reload or Cancel instead of silently replacing it.
- Files that aren't valid UTF-8 are no longer opened for editing, because saving would corrupt them.
- Files with mixed line endings show *Mixed→LF* or *Mixed→CRLF* in the status bar and warn that saving converts them.

### Chat

- Answering a permission prompt after the agent exited no longer crashes the app. Open prompts are cancelled on exit, restart, End session and delete.
- Malformed messages from an agent, and failures such as attachments that can't be written, show an error instead of crashing.
- End session and Restart during a reply no longer leave the chat marked Failed, and no longer leak an agent process.
- A first message queued while the agent was still starting is saved, and sent when the chat resumes. Attachments queued that way are lost if the app dies first.
- "Needs you" notifications clear once the prompt is answered.
- Two attachments with the same name in one message no longer overwrite each other.

### Projects and git

- Commit file lists handle non-ASCII, quoted and tab-containing paths, so their diffs open.
- Git warnings can no longer make the branch show as detached, and large repositories aren't cut off at 64 KB of status output.
- If a stash-and-switch fails, the stashed changes are restored, or the app tells you they're in `stash@{0}`.
- The file tree builds its rows off the main thread.

### Runtime

- Bootstrap symlinks are checked so they can't point outside the install folder. A missing published checksum is logged.
- Requests from the runtime to open a URL or install an APK can't be handled twice, and requests over 8 KB are ignored.
- Old web-run folders are cleaned up after startup.

### Validation

- 92 Android/JVM unit tests, including new tests for pairing and encryption, atomic saving, encoding and line-ending detection, and git `-z` parsing.
- Checked on an arm64 phone: every main screen opens, the editor refuses Latin-1 files, the mixed line-ending warning appears, and the changed-on-disk dialog works with Overwrite. Chat, git, Run and two-phone pairing still need testing on a phone with agents and a second device.

### Before installing

- Install 0.0.3 on **both** phones if you use two-phone sharing.
- This is still a sideloaded alpha: application ID `com.termux`, targetSdk 28, debug signing key. Install over your existing copy to keep the runtime and chats.
