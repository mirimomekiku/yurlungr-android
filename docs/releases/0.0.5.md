# Yurlungr 0.0.5

Yurlungr 0.0.5 makes chats easier to run from a distance (a message queue, approvals and replies from
notifications, hands-free voice) and turns projects into a fuller workspace: templates, per-project databases,
pull request review, web build and deploy, dependency updates and fixes for phone-specific build failures.

see Settings → **Licenses and notices**. Third-party components keep their own licenses.

Changes since [0.0.4](0.0.4.md).

### Chat

- **Message queue:** type while the agent works; messages wait as chips and send in order when the turn ends.
  *Send now* stops the turn and sends the first. Queued messages can be edited, reordered or removed.
- **Artifacts:** Chat ⋮ → Artifacts lists the files the agent created or edited, including files its commands
  wrote, with previews, Copy path, Share and **Save a copy** (to Downloads or any folder). *Save all* copies
  every artifact into a folder it remembers.
- **File previews:** pictures (pinch and double-tap zoom), HTML/SVG pages (sandboxed, network loads blocked) and
  CSV/TSV tables open as previews from Files, chat links and Artifacts.
- **Diagrams and math:** Mermaid and math blocks draw in replies, with Code and Copy. The renderers download once
  (3.7 MB, pinned and SHA-256 checked) when you tap *Draw diagrams* or turn it on in Settings.
- **Approval rules:** auto-approve read, search, fetch, think, edit or run requests per project, or tap
  *Always allow … here* on a permission card. Matches are approved once and noted in the chat.
- **Notifications:** an approval waiting gets a high-priority notification with **Allow** and **Deny** buttons, and
  a sticky in-app banner. A turn that finishes in the background posts a quiet notification with **Reply**.
- **Read aloud and hands-free:** a speaker button reads a reply (code, diagrams and tables summarized); per chat,
  read each reply as it finishes; hands-free mode speaks, listens and sends, and answers approvals by voice.
  Speed, pitch, language and voice are in Settings.
- **Organize chats:** pin, rename, and group the sidebar by day or project; export a chat as Markdown or JSON.
- **Context meter:** from 60% context use the composer shows a meter, with the agent's `/compact` and *New chat
  with summary*.
- **Folding tool output:** long output shows its first and last lines, with Jump to error, Show all and Copy.
- **Prompts, drafts, voice and @mentions:** a saved-prompt library, unsent text kept per chat, a mic button, and
  `@` file suggestions. Long-press your own message to copy it.
- **Commands sheet** and **Skills & commands:** browse the agent's slash commands, and list, create, install (from
  Git), open and delete skills and custom commands per agent; run each agent's plugin commands in a terminal.

### Projects

- **New project from a template:** 17 templates (static site, Vite React/Vue/Svelte, Next.js, Astro, Express, Hono,
  FastAPI, Flask, Django, Laravel, Go, Rust axum, Expo, Flutter (experimental), empty). Each checks its toolchain,
  writes starter files and AGENTS.md, installs dependencies, runs it and opens the preview. Cloning can install and
  run straight away too.
- **Overview tab:** git and PR status, last checks, web server, databases, recent chats, dependencies, runtime
  version warnings and disk use.
- **Pull requests:** open PRs (mine or review requested) with description, checks, conversation, inline comments and
  per-file diffs. Approve, request changes, comment, check out and merge, or ask an agent to review or fix checks.
- **Databases:** start and stop PostgreSQL, Redis and MariaDB per project (127.0.0.1 only), with connection string
  copy and *Add to .env*.
- **.env editor:** values hidden until tapped, comments and order kept, missing variables from `.env.example`
  shown, and a warning (with a fix) when `.env` isn't ignored by git.
- **Dependency updates** for npm, pnpm, Yarn 1, Bun, pip, uv, Poetry, Go and Cargo: majors marked, take the safe
  ones, then run the checks.
- **Phone-specific fixes:** recognizes common Android/Termux failures (esbuild, Next.js SWC, Rollup and sharp native
  modules, node-gyp, Python wheels, missing compilers, file watchers, busy ports), with *Run fix* where the fix is
  certain and *Ask the agent* otherwise. Warns when a project wants a runtime version the phone doesn't have.
- **Python venvs:** setup creates `.venv`, and every process started in the project uses it.
- **Free up space:** regenerable folders per project (node_modules, build outputs, .venv, caches) and shared package
  caches, with sizes and link-safe deletion that never touches source or `.git`.
- **Find code** across all projects (plain or regex, file and project filters), with ripgrep when installed.
- **Ubuntu environment** pack (proot-distro), and an experimental Flutter pack inside it for web projects.

### Web

- **Public links:** share a running web server (or any listening port) through cloudflared's account-free Quick
  Tunnel, after a confirmation. Links are random, change each run and stop with their server; a QR code is shown.
- **Preview:** console messages and failed requests in a panel, Phone/Tablet/Desktop widths, Open in browser.
- **Port conflicts:** Run names the process holding a port and offers Stop (the app's own processes only) or the
  next port.
- **Restart on save** per run config, keeping the port and public link up.
- **API tester:** send requests to the local server, with saved requests and routes imported from OpenAPI/Swagger.
- **Build & deploy:** build, preview the output, save it as a zip, or deploy to Cloudflare Pages, Netlify or Vercel.
  Tokens are sealed with the Android Keystore.

### Around the app

- **Getting started** card on the start screen: Linux environment, a runtime, a signed-in agent, a project and a
  first run, each checked against real state. The tour moved to Settings.
- **Activity** (sidebar): chats that are working or waiting, with plan steps, queued messages and Stop; per-agent
  chats, prompts, tokens and cost.
- **Search everything** also finds text inside chats.
- **Quick ask:** an *Ask an agent…* bar on the home widget and a launcher shortcut. A Quick Settings tile and the
  widget show what agents are doing.
- **Wide screens and keyboards:** at 840 dp and wider the sidebar stays pinned and files or previews sit beside the
  chat. Shortcuts include Ctrl+N, Ctrl+K, Ctrl+P, Ctrl+Shift+F and Ctrl+Enter to send; Ctrl+/ lists them all.

### Security and reliability

- **Verified downloads:** the Termux bootstrap is pinned and checked; setups use https only; npm tarballs, release
  assets and the Android cmdline-tools are checked against their hashes.
- **Agent file access** can't reach the app's own data (settings, chats, checkpoints), and approval rules only
  match when every path a tool call names is inside the project.
- **Two-phone sharing:** pairing secrets are sealed with the Keystore; frames are size-guarded across split
  handshakes; the Tailscale address range is accepted only on the Tailscale interface; a refused connection never
  wipes the pairing secret.
- **Git** treats paths literally (discarding `app/[id]/page.tsx` no longer touches `app/i/…`), and Get latest
  and branch switches only pop a stash they created.
- **Runtime requests** are labelled and rate-limited, APKs reach the installer through a staged copy, and a reused
  process id is never signalled.
- **Editor:** unsaved buffers are backed up, LSP work is off the main thread, and merge saves refuse files that
  changed after the merge screen opened.
- **Chats:** saved chats load off the main thread; checkpoint restores can't overlap a turn; a malformed entry no
  longer erases history; agents that fail to start are stopped.

The APKs are still signed with the alpha (debug) key, so 0.0.5 installs over 0.0.4 and keeps your runtime and
chats.
