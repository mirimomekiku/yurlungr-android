# Yurlungr 0.0.5 (unreleased)

Changes since [0.0.4](0.0.4.md). This file grows until the release is cut.

### Chat

- **Message queue:** type while the agent works; messages wait as chips and send in order when the turn ends.
  *Send now* stops the turn and sends the first. Works for every agent.
- **Artifacts:** Chat ⋮ → Artifacts lists the files the agent created or edited, including files its commands
  wrote, with previews, Copy path and Share.
- **File previews:** pictures (pinch and double-tap zoom), HTML/SVG pages and CSV/TSV tables open as previews from
  Files, chat links and Artifacts; Share and Copy path on each.
- **Approval rules:** auto-approve read, search, fetch, think, edit or run requests per project, or tap
  *Always allow … here* on a permission card. Matches are approved once and noted in the chat.
- **Needs your answer:** a high-priority notification (sound and vibration) only when an approval is waiting,
  plus a sticky in-app banner that stays until it's answered. Finished turns no longer notify.
- **Prompts, drafts, voice and @mentions:** a saved-prompt library, unsent text kept per chat, a mic button, and
  `@` file suggestions.
- Long-press your own message to copy it.

- **Commands sheet** and **Skills & commands:** browse the agent's slash commands, and list, create, install (from Git),
  open and delete skills and custom commands per agent; run each agent's plugin commands in a terminal.

### Around the app

- **Activity** (sidebar): chats that are working or waiting, with plan steps, queued messages and Stop; per-agent
  chats, prompts, tokens and cost.
- **Search everything** also finds text inside chats.
- **Quick ask:** an *Ask an agent…* bar on the home widget and a launcher shortcut open New chat with the
  keyboard up. Opening the sidebar now hides the keyboard.

### Projects

- **Pull requests:** Git actions shows *Open pull request #N*, or *Create pull request* once the branch is pushed.
- **Public links:** share a running web server (or any listening port) through cloudflared's account-free Quick
  Tunnel. A confirmation comes first, links are random and change each run, and a link stops with its server.
