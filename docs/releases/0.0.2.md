Yurlungr 0.0.2 adds local web previews, richer Markdown, safer terminal session controls, and clearer project status.

### Local web previews

- Projects detect runnable Vite apps and static HTML sites, including common monorepo folders.
- Run setup selects the app, package manager, script, port and dependency installation; custom commands are available for Vite setups.
- Open previews in the phone's browser, inspect terminal logs, and stop or restart with confirmation.
- Servers bind to loopback by default. Managed terminals track actual server exits and clean up child processes.
- Next.js, Astro, Nuxt, CRA and Angular are detected as candidates; their launch setups still need device validation.

### Markdown and project files

- Chat replies render CommonMark headings, nested lists, emphasis, tables, strikethrough, code and links.
- Markdown files open in a rendered viewer with an Edit action and relative-file navigation.
- Git details adds ignored/not-ignored labels and All, Not ignored, Ignored and Uncommitted views. Deleted paths appear in Uncommitted.

### Terminal and chat

- Long-press session tiles for a bottom sheet with Rename, Restart, End and Close. Destructive actions and shortcuts require confirmation.
- A keyboard icon toggles the extra-key rows and remembers their visibility.
- The compact MOTD shows session, folder, branch, agent/approval counts and account sign-in hints. Run `yurlungr-status` to refresh.
- New local and remote chats offer per-chat Skip permissions (YOLO) setup, using the agent's advertised ACP mode or Antigravity's launch flag.
- Editor preferences load through lifecycle effects, and the ACP client reports the installed APK version.

### Validation

- 65 Android/JVM unit tests and 6 Node supervisor integration tests.
- On-device checks cover static previews, loopback health, duplicate prevention and managed End/Restart/Close.
- Vite 8.3.6 was checked on arm64 for preview loading, module transformation, HMR and clean shutdown.
- Release packages include arm64-v8a, armeabi-v7a, x86_64, x86 and universal APKs, with SHA-256 checksums.

### Before installing

- Choose the APK matching your device; arm64-v8a fits most modern phones. Universal includes every supported ABI.
- This remains a sideloaded alpha using application ID `com.termux` and targetSdk 28. It cannot coexist with a separate Termux installation.
- Alpha builds still use the debug signing key. Keep an existing installation rather than uninstalling if you want to preserve runtime files and chats.
- Other CPU architectures and project-specific native web dependencies need additional compatibility testing. Account indicators use credential-file presence and do not display credentials; Antigravity remains unknown.
