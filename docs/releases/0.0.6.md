# Yurlungr 0.0.6

Yurlungr 0.0.6 puts the whole developer setup in one place, **Install tools** in System checks, and makes cloned
code safer to work with: repositories you don't own start untrusted until you say so. It also adds live agent
terminals, approvals that show what you approve, public links that expire and need a key, single-hunk staging and
a long list of fixes from a full audit.

Changes since [0.0.5](0.0.5.md).

### System checks

- **Install tools:** a card at the top of System checks says what's left to install and opens a sheet with
  two tabs.
  - **Essentials:** Git, GitHub CLI, Node.js and npm, ripgrep, the coding agents, Python, pip, uv and SQLite.
    Those not installed start ticked, so installing them is open → **Install**.
  - **Optional packs:** all 43 packs besides Python (covered by the essentials) plus the Android SDK, grouped
    by kind, with a search and **All · Not installed · Installed** filters.
- Installed items show their version; *Needs repair*, *Partly installed* or *Needed by …* appear only when
  they apply. What an item needs (Python for pip and uv, the developer tools for the agents, Ubuntu for
  Flutter) is ticked and locked with it.
- The footer says how much free space the choice needs against what's free, in red when it won't fit.
- Everything picked installs in one terminal run: essentials and package-only packs in a single package
  run, then the agents, Ubuntu, Flutter, the browser and the SDK setups one after another. A pack installed
  this way clears an older failed run of its own setup from System checks.
- Ctrl-C or closing the tab stops the whole Install tools run, not just the current setup.
- **Reinstalling the base system** swaps the old one out at once instead of deleting it file by file, then
  offers to reinstall the packages, setups and agents you had. A first install falls back to a pinned
  bootstrap when GitHub's API is rate-limited.
- System checks no longer asks apt for pending updates on every return to the app, and checks tools faster.
- A process killed by Android (signal 9) now says so, with a link to the background process limit fix.

### Trusted projects

- Cloning a repository you don't own marks it **untrusted**. Until you tap **Trust this project**, it
  doesn't install and run after cloning, run the automatic setup, start language servers, load its Prettier
  config, put a committed `.venv` on PATH, or give its `.mcp.json` servers to agents.
- Pull request **Check out** runs with git hooks off; **Merge** only merges the commit you reviewed; PR text
  reaches agents marked as data, not instructions.

### Chat

- **Approvals show what you approve:** the command, files and changes in the card and the notification.
- Approval rules never auto-approve edits to agent or tool configuration (`.claude/`, `.mcp.json`, `.env`,
  git hooks…), and search or fetch rules need files in the project.
- **Commands the agent runs** (ACP terminals) show live output with **Stop**.
- The project's **MCP servers** are passed to every agent (trusted projects).
- Tool-card file locations open the editor at that line. Usage and cost survive restarts.
- Ending or deleting a chat now also stops what the agent started (dev servers, MCP servers, shells).
- Agent edits keep a file's permissions (`gradlew` stays executable).
- Messages from a paired phone while the agent works are queued instead of lost, and the queue shows there.
- A second open approval keeps its notification; a checkpoint restore waits while another chat works in the
  same folder; scrolling up during a long reply stays put; long replies stream more smoothly and big tool
  output no longer bloats memory.

### Projects and git

- **Unfinished merge, rebase, cherry-pick or revert:** a banner with Continue / Conclude merge / Abort, and
  "Fix conflicts" now continues the right operation instead of touching your stashes.
- **Stage single hunks**, **clean up merged and gone branches**, rename branches, **history of a file**, and
  history paging.
- Your work left in a stash by *Get latest changes* gets a **Restore** banner; stash actions use the stash's
  SHA and Drop asks first.
- Commits with slow hooks no longer time out after 60 s, and finish even if you leave the screen.
- Big diffs say when they're cut short; detached HEAD no longer offers Push; a stale `index.lock` can be
  removed from the error; staging no longer rescans the whole project.

### Web, editor and data

- **Public links** work with Vite, Astro, Nuxt, SvelteKit and webpack dev servers, expire (1 h by default),
  show a notification with Stop, and need an access key that's included in the link you share.
- **Deploy** runs pinned CLI versions from the app's own folder, so a project can't intercept your token.
- **Files an agent edits** reload in the editor; with unsaved edits you choose Reload, Diff or Keep mine.
- Format no longer overwrites what you type meanwhile; the merge editor keeps encodings, line endings and
  final newlines, and recognises only git's real conflict markers.
- Preview: **Clear site data**, cleared automatically when another project uses the same port.
- The Databases screen warns before writing a password into a committed `.env`; saved API tester headers
  are encrypted; the file watcher polls less when nothing changes.

### Runtime

- `xdg-open` / `termux-open` open local files (HTML reports, PDFs) in the right app.
- Install prompts and links from the terminal show as notifications while the app is in the background.
- Removing a pack no longer removes packages you installed yourself.
- Interrupted package installs are repaired with `apt-get -f install`.
- Themed (monochrome) launcher icon on Android 13+.

### Worth knowing

- Public links to Yurlungr's runs now need their access key; share the link the app copies, which includes it.
- Projects you cloned before 0.0.6 stay trusted. Only new clones of repositories you don't own start untrusted.
- Deploys use pinned CLI versions (wrangler 4.156.0, netlify-cli 27.16.0, vercel 65.8.0) from the app's own folder.
- The APKs are still signed with the alpha key, so 0.0.6 installs over 0.0.5 and keeps your runtime and chats.
